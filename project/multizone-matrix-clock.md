A **WiFi-enabled LED matrix clock** for the **ESP8266** that displays
time from multiple timezones at once. Automatic **NTP** sync, DST
handling, and a small built-in web UI for on-device configuration.

- Stack: C++ (Arduino / ESP8266)
- Repo: [github.com/hamidfzm/MultiZoneMatrixClock](https://github.com/hamidfzm/MultiZoneMatrixClock)
